# Contributing to Obfuskoder

Thanks for your interest in Obfuskoder! Contributions are welcome, in the form
of both **issues** and **pull requests**.

A note on expectations: Obfuskoder is maintained in spare time, so please don't
expect immediate responses. Issues and pull requests are reviewed as time
allows — your patience is appreciated.

## Reporting issues

Found a bug or have an idea? [Open an issue](https://github.com/alderete/Obfuskoder-Mac/issues).
For bug reports, it helps to include:

- What you did, what happened, and what you expected instead
- Your macOS version and the Obfuskoder version (**Obfuskoder ▸ About Obfuskoder**)
- Steps to reproduce, if you can

## Pull requests

- For anything non-trivial, please open an issue first so we can talk it through
  before you invest time.
- Keep each pull request focused on a single concern — it's easiest to review.
- Describe what the change does and why.
- Make sure the app builds and the tests pass. The `ObfuskoderKit` unit tests
  run with `swift test` from the `ObfuskoderKit/` directory.
