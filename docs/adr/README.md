# Architecture Decision Records

Architecture Decision Records (ADRs) capture durable technical choices, their
context, consequences, and rejected alternatives. Product behavior belongs in a
design specification; an ADR explains the constraints and ownership model used
to realize it.

## Statuses

- **Proposed:** under review.
- **Accepted:** current architectural direction.
- **Superseded:** replaced by a later ADR; retained as history.
- **Rejected:** considered but not adopted.
